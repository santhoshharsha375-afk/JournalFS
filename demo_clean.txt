   JOURNALFS  -  a filesystem that survives crashes
============================================================

  STEP 1 - Create a disk image
----------------------------------------------------------------
      > mkfs_journalfs demo.img
        mkfs_journalfs: created demo.img (16962 blocks, 16384 data blocks, 1024 inodes, 256 journal slots)

  STEP 2 - Create a file and write into it
----------------------------------------------------------------
      > create /hello.txt
        OK: file created
      > write /hello.txt 'Hello Reviewer!'
        OK: content saved (journaled first)

  STEP 3 - Read the file back
----------------------------------------------------------------
      > read /hello.txt
        RESULT: Hello Reviewer!

  STEP 4 - List files in the disk
----------------------------------------------------------------
      > ls /
        .

      > journal

        slot 4: type=3 txid=1 seq=4 gen=1 block=0 len=0
        ... type 1=BEGIN  2=UPDATE  3=COMMIT  <- every change is logged
             BEFORE it is written to the real location
